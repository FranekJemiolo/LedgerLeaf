# LedgerLeaf GitHub Pages Demo

A fully functional, local-first expense tracking demo that works entirely in your browser without any database or backend requirements.

## 🚀 Features

### Core Functionality
- **Import/Export**: Upload CSV or Excel files and export data in multiple formats
- **Session Management**: All data stored in localStorage for privacy
- **Real-time Updates**: Instant calculations and statistics
- **Responsive Design**: Works on desktop, tablet, and mobile devices

### Privacy & Security
- **No Database Required**: Works entirely offline
- **Local Storage**: Data never leaves your browser
- **Privacy-First**: No tracking or analytics beyond what's in your session

### Demo Capabilities
- **File Import**: Parse CSV/Excel files with automatic recurring detection
- **Data Preview**: See your imported data before confirming
- **Export Options**: Download your data in CSV format
- **Session Statistics**: Track expenses, monthly totals, and recurring items
- **Progressive Web App**: Install as a native app on any device

## 🛠️ Technical Details

- **Frontend**: Pure HTML, CSS, and JavaScript
- **Storage**: localStorage for session persistence
- **File Processing**: Client-side CSV/Excel parsing
- **Design System**: Material Design with custom CSS variables
- **Icons**: Material Symbols font icons
- **Responsive**: Mobile-first responsive design
